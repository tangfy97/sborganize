# Roadmap

## Available in the public alpha

- Installable CLI, bundled offline demo, short welcome and grouped help.
- In-terminal guides, English/Chinese entry points and focused reference docs.
- Rules-first previews, saved target inspection, private config and backup browsing.
- Explicit emoji policies, all-app reasons, folder ordering and sequential page packing.
- Self-owned USB adapter, exact backups and gated apply/restore with strict readback.
- Optional Apple inference and explicitly opted-in, resumable OpenRouter review.
- Advisory review separated from writable plans; local recheck needs no credits.
- Linux/macOS fixture CI and an installed-wheel workflow outside the source tree.

## Next

- Broader hardware round-trip and apply coverage with redacted protocol fixtures.
- A first independently verified hardware restore and a numerical iOS support matrix.
- Better classification evidence and actionable unresolved-app explanations.
- Feedback from first-time CLI users, especially configuration and policy editing.

One development iPhone completed a 248-app, 18-folder policy write. The user
confirmed the result and made manual refinements. That observation is not a
broad compatibility claim; see [verification details](COMPATIBILITY.md).

## Later, if useful

- Optional App Store metadata lookup with explicit network opt-in.
- A terminal policy editor to reduce manual JSON editing.
- Non-English command output and more shell-completion examples.
- App inventory beyond the Home Screen if a reliable, narrowly scoped API exists.

## Outside this project's scope

- A branded GUI or consumer App Store app.
- Implicit cloud inference, raw layout uploads or Ollama setup.
- Wrapping Unjiggle as the device read/write path.
- Automatic app uninstall or deletion.
