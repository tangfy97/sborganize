# Guides

Start with [the quick start](QUICKSTART.md), or run `sborganize guide` from any
installed copy. No phone or network is needed to read the built-in guides.

- [Quick start](QUICKSTART.md): try, rehearse, connect, preview, apply.
- [CLI reference](CLI.md): commands, flags, machine output and local files.
- [Classification](CLASSIFICATION.md): domain choices, service regions and overrides.
- [Policies](POLICY.md): exhaustive emoji redesign and full folder pages.
- [Safety and recovery](SAFETY.md): write stages, failure handling and undo backups.
- [Troubleshooting](TROUBLESHOOTING.md): common errors and concrete next steps.
- [Compatibility](COMPATIBILITY.md): tested scope and current limits.
- [Optional models](MODELS.md): Apple, explicit OpenRouter and credit-free routes.
- [Configuration example](examples/config.toml): commented defaults.

For contributors: [development](DEVELOPMENT.md), [releasing](RELEASING.md),
[plans](plans/README.md), [research](research/springboard-icon-state.md),
[privacy](../PRIVACY.md) and [security reporting](../SECURITY.md).
